The filter() function in JavaScript is a handy method available for arrays. It creates a new array by including only the elements that pass a specified test (or condition) provided by a callback function. The original array remains unmodified.
Syntax:
array.filter(callback(element, index, array), thisArg)


- callback is the function executed for each element.- element is the current item in the array.
- index (optional) is the index of the current item.
- array (optional) is the array being iterated.

- thisArg (optional) is a value used as this inside the callback function.

Example 1: Filter Even Numbers
const numbers = [1, 2, 3, 4, 5, 6];
const evenNumbers = numbers.filter(num => num % 2 === 0);

console.log(evenNumbers); // Output: [2, 4, 6]


Here, the filter function goes through each element in the array and includes only the numbers that are divisible by 2.
Example 2: Filter Strings Based on Length
const words = ["apple", "cat", "banana", "dog", "elephant"];
const longWords = words.filter(word => word.length > 3);

console.log(longWords); // Output: ["apple", "banana", "elephant"]


This example filters out words with lengths greater than 3.
Example 3: Filtering Objects
const people = [
  { name: "Alice", age: 25 },
  { name: "Bob", age: 17 },
  { name: "Charlie", age: 30 }
];

const adults = people.filter(person => person.age >= 18);

console.log(adults);
// Output: [{ name: "Alice", age: 25 }, { name: "Charlie", age: 30 }]


When to Use filter()
Use filter() whenever you need to extract a subset of an array based on specific conditions. It's ideal for creating more manageable data sets from larger ones.

Let's explore some more complex scenarios where the filter() function shines. Here are two examples showcasing additional use cases:
Example 1: Filtering Nested Arrays
Suppose you have a list of students and their scores in various subjects, and you want to filter out the students who scored above 90 in math:
const students = [
  { name: "Maya", scores: { math: 92, english: 85 } },
  { name: "Arjun", scores: { math: 88, english: 90 } },
  { name: "Lila", scores: { math: 95, english: 78 } }
];

const mathToppers = students.filter(student => student.scores.math > 90);

console.log(mathToppers);
// Output: [{ name: "Maya", scores: { math: 92, english: 85 } }, { name: "Lila", scores: { math: 95, english: 78 } }]


What’s Happening?
The callback function navigates the nested object structure to check the math score for each student. Only those with scores greater than 90 are included in the mathToppers array.

Example 2: Filtering with Regex
Imagine you want to filter out items from a list of emails that belong to a particular domain:
const emails = [
  "milan@example.com",
  "john@sample.org",
  "arushi@example.com",
  "admin@company.net"
];

const exampleEmails = emails.filter(email => /@example\.com$/.test(email));

console.log(exampleEmails);
// Output: ["milan@example.com", "arushi@example.com"]


What’s Happening Here?
The callback uses a regular expression (/@example\.com$/) to test if the email ends with @example.com. The filter() method only keeps those emails that match the regular expression.

Advanced Tips for filter()
- Chaining with Other Methods: You can combine filter() with map() or reduce() for more complex transformations or computations.
- Performance Consideration: While filter() is efficient, avoid overusing it for very large arrays. If needed, consider optimizing with sorted data or alternative approaches.
- Reusable Conditions: For complex conditions, store your test logic in a separate function and reuse it within filter().

Chaining methods is a powerful feature in JavaScript that allows you to combine multiple array methods in a single, clean, and readable expression. This is especially useful when you want to perform a series of transformations or filtering on an array.
Example 1: Filtering, Mapping, and Sorting
Let's say you have an array of people, and you want to extract names of adults (age ≥ 18), convert them to uppercase, and sort them alphabetically.
const people = [
  { name: "Milan", age: 25 },
  { name: "Arjun", age: 17 },
  { name: "Priya", age: 30 },
  { name: "Ravi", age: 15 }
];

const result = people
  .filter(person => person.age >= 18)       // Step 1: Keep only adults
  .map(person => person.name.toUpperCase()) // Step 2: Convert names to uppercase
  .sort();                                  // Step 3: Sort names alphabetically

console.log(result);
// Output: ["MILAN", "PRIYA"]


Here, each method is executed in sequence:
- filter() removes non-adults from the array.
- map() transforms the names into uppercase.
- sort() arranges the names alphabetically.


Example 2: Calculate Average of Filtered Values
Suppose you have an array of numbers, and you want to calculate the average of numbers greater than 50.
const numbers = [20, 55, 80, 45, 60];

const average = numbers
  .filter(num => num > 50)       // Step 1: Keep numbers greater than 50
  .reduce((sum, num, _, arr) => sum + num / arr.length, 0); // Step 2: Calculate average

console.log(average);
// Output: 65


Here’s what happens:
- filter() extracts numbers greater than 50.
- reduce() calculates the average by summing the filtered numbers and dividing by their count (using arr.length).


Example 3: Remove Duplicates and Sort
Chaining can help remove duplicates and sort an array, for example:
const data = [5, 10, 5, 20, 10, 30];

const uniqueSorted = [...new Set(data)] // Remove duplicates
  .sort((a, b) => a - b);              // Sort numbers in ascending order

console.log(uniqueSorted);
// Output: [5, 10, 20, 30]



Why Use Chaining?
- Readability: Each method focuses on a single transformation, making code easier to read and maintain.
- Efficiency: It's concise and avoids creating intermediate variables unnecessarily.
